Klantenbeheer

Over dit project
Dit project is een eenvoudige webapplicatie waarmee klantgegevens beheerd kunnen worden. De applicatie is gemaakt met PHP, MySQL en Bootstrap.

Functionaliteiten
Klanten bekijken in een overzicht.
Nieuwe klanten toevoegen.
Bestaande klantgegevens aanpassen.
Klanten verwijderen.

Gebruikte technieken
PHP
MySQL
HTML
CSS
Bootstrap

Installatie
Download of clone deze repository.
Plaats de projectmap in de htdocs-map van XAMPP.
Start Apache en MySQL via het XAMPP Control Panel.
Importeer de database in phpMyAdmin.
Open het project via http://localhost/eenvoudige_database/eindopdracht/index.php.
